Ekspor & Backup Basis Data Relasional

Anda dapat mengunduh seluruh skema database relasional lengkap dengan master kelas, data siswa, master guru/pengawas, template berita acara, arsip dokumen tersimpan, serta pengguna sistem dalam format MySQL/MariaDB (.sql), Excel (.xlsx), maupun JSON untuk migrasi atau pencadangan berkala. Setiap kali data diubah di aplikasi, file database.sql secara otomatis diperbarui secara realtime di server.

MySQL / MariaDB Dump (.sql)

File SQL dump lengkap dengan struktur CREATE TABLE dan INSERT untuk classes, students, teachers, exam_templates, users, dan archives.

Master Siswa Excel (.xlsx)

Ekspor seluruh data siswa lengkap dengan NIS, Nama, Kelas, Tingkat, dan Program Keahlian dalam lembar kerja Excel siap pakai.

Master Guru & Pengawas (.xlsx)

Ekspor seluruh data dewan guru dan pengawas ujian lengkap dengan NIP dan Nama Lengkap bertitel resmi.

JSON Database Dump (.json)

Seluruh struktur objek basis data yang dapat diimpor langsung oleh engine Node.js atau disimpan offline.

Inisialisasi & Reset Ulang Basis Data
Mengembalikan seluruh 9 sheet Google Spreadsheet ke struktur dan data seeder default resmi SMK NEGERI FYJ CHANNEL.
